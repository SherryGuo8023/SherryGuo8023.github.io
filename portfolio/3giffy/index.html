Anime Giffy

A Discord bot that turns a text description into a chibi character GIF.

  • 2025
  • Side project
  • Add to Discord

A Discord bot that turns a text description into a chibi character GIF. Describe what you want, pick a pose, and use it as a sticker or reaction. Type /create to start.

How it works

Describe your character. Type what you want your character to look like and do; the bot builds the character silhouette from the text.

Choose an animation. Pick from a set of preset animations and adjust poses and expressions.

Generate. The character comes to life as a GIF in a few seconds.

Use it in Discord. Share directly in chat and keep a personal collection.
