# sherryguo8023.github.io

Personal site of Yunjia Guo. Plain HTML and CSS, generated by a small Python script and served by GitHub Pages as static files (`.nojekyll`).

## Editing

- Content: `_src/content/` (projects as Markdown with front matter, `publications.yml`, `talks.yml`, `cv.md`, `cats.md`)
- Page templates and home-page copy: `_src/build.py`
- Styles: `_src/style.css`
- Images: `images/`, video: `video/`

## Building

    pip install markdown pyyaml
    python _src/build.py

Commit `_src/` together with the generated files at the repo root, then push `master`.
